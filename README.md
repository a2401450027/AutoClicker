Windows 记录鼠标点击、滚轮、键盘按键，记录的操作支持单步修改，操作回放支持单次和指定间隔时间的多次重复执行

## 使用方法

1. **记录鼠标操作**：
   - 点击"开始记录"按钮或按`F7`键
   - 执行您需要记录的鼠标操作
   - 完成后点击"停止记录"按钮或按`F8`键
2. **回放鼠标操作**：
   - 设置执行次数
   - 点击"开始回放"按钮或按`F10`键
   - 需要停止时点击"停止回放"按钮或按`F9`键
3. **管理操作记录**：
   - 记录完成后会自动保存到列表中
   - 双击列表中的记录项进行加载
   - 右键点击可以进行更多操作
